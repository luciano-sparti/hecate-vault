# Add Encryption‑as‑Service (gRPC) to Hecate Vault

## Goal Description
We extend **Hecate Vault** so it can operate not only as a local CLI but also as a software HSM offering **encryption‑as‑a‑service**. The service will expose a gRPC API (protobuf) that clients can call to encrypt, decrypt, seal, and unwrap keys. The implementation remains in **Rust** to retain memory‑safety, zero‑cost abstractions, and easy integration with the existing cryptographic stack.

## User Review Required
> [!IMPORTANT]
> *The service will run as a background daemon exposing a network port. Consider any firewall, authentication, and multi‑tenant isolation requirements before deployment.*
> 
> *We will add a `tonic`‑based gRPC server. If you need TLS termination or mutual TLS, let us know now so we can include the necessary configuration.*

#### [NEW] [src/service/proto/encryption.proto](file:///c:/Users/Luciano/Projects/Encrypted%20Secrets%20Vault%20CLI/src/service/proto/encryption.proto)
```proto
syntax = "proto3";
package hecate.service;

service EncryptionService {
  rpc Encrypt (EncryptRequest) returns (EncryptResponse);
  rpc Decrypt (DecryptRequest) returns (DecryptResponse);
  rpc WrapKey (WrapKeyRequest) returns (WrapKeyResponse);
  rpc UnwrapKey (UnwrapKeyRequest) returns (UnwrapKeyResponse);
}

message EncryptRequest {
  bytes plaintext = 1;
  string namespace = 2; // optional logical grouping
}
message EncryptResponse {
  bytes ciphertext = 1;
  bytes nonce = 2;
  bytes tag = 3;
}

message DecryptRequest {
  bytes ciphertext = 1;
  bytes nonce = 2;
  bytes tag = 3;
  string namespace = 4;
}
message DecryptResponse {
  bytes plaintext = 1;
}

message WrapKeyRequest {
  bytes dek = 1; // data‑encryption‑key to wrap
}
message WrapKeyResponse {
  bytes wrapped_dek = 1;
}

message UnwrapKeyRequest {
  bytes wrapped_dek = 1;
}
message UnwrapKeyResponse {
  bytes dek = 1;
}
```
